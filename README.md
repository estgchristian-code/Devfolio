# Devfolio

Portfólio pessoal desenvolvido para apresentar minha trajetória profissional, habilidades, experiências e projetos na área de Desenvolvimento Web.

O projeto possui uma interface moderna e responsiva, com integração à GitHub REST API para buscar e exibir automaticamente meus repositórios públicos.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Lucide Icons
- Git e GitHub

## Funcionalidades

- Apresentação profissional e trajetória acadêmica.
- Exibição de experiências e habilidades técnicas.
- Integração com a GitHub REST API.
- Busca automática de repositórios públicos.
- Classificação e filtragem de projetos.
- Seleção de projetos em destaque.
- Cache local e sincronização automática.
- Links diretos para os repositórios.
- Interface responsiva.

## Integração com GitHub

A integração utiliza a API pública do GitHub para consultar os repositórios do perfil, sem necessidade de autenticação ou backend.

Os dados são armazenados em cache no navegador e atualizados periodicamente, reduzindo requisições desnecessárias.

## Executar localmente

O projeto não necessita de instalação de dependências ou configuração de backend.

1. Clone o repositório:

```bash
git clone https://github.com/estgchristian-code/Devfolio.git
```

2. Entre na pasta:

```bash
cd Devfolio
```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server do VS Code.
